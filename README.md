# 🌑 **NØXtem**
> A low-poly suspense and action game that shifts between **first-person** and **third-person / hack-and-slash** gameplay, developed in **Unity**.

---

## 🧩 **Engine & Programming Language**
- 🎮 **Unity** 
- 🖥️ **C#**
