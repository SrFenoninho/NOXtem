# **NØXtem**
> A low-poly suspense and action game that shifts between **first-person** and **third-person / hack-and-slash** gameplay, developed in **Unity**.

---

## **Engine & Programming Language**
- **Unity** 
- **C#**

---

## **Fan Game Disclaimer**

NØXtem contains an alternate version featuring **Springtrap / William Afton**, a character from the *Five Nights at Freddy's* franchise.
This project is an **unofficial fan game** 
*Five Nights at Freddy's* and all related characters are the intellectual property of **Scott Cawthon**.
